## ⭐ Featured Project: agentgate

<div align="center">

[![agentgate](https://img.shields.io/badge/rohancoding5-agentgate-0e1624?style=for-the-badge&logo=github&logoColor=f2c48f)](https://github.com/rohancoding5/agentgate)
![TypeScript](https://img.shields.io/badge/TypeScript-0e1624?style=for-the-badge&logo=typescript&logoColor=3178c6)

</div>

A checkpoint that sits between AI agents. Every message is screened for **prompt injection**, **leaked secrets** and **out-of-bounds tool calls** before it reaches the other side, so agents don't have to trust each other.

```
Agent A  ──▶  agentgate  ──▶  Agent B
                 │
                 ├─ prompt injection?    blocked
                 ├─ leaked secret?       blocked
                 └─ out-of-bounds tool?  blocked
```
